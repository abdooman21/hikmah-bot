# بوت حكمة التعليمي (Hikmah Discord Bot)

بوت ديسكورد تعليمي مفتوح المصدر مكتوب بلغة Go، يقدّم مسابقات وأسئلة إسلامية تفاعلية داخل خوادم ديسكورد.  
يدعم البوت جلسات مسابقات متعددة اللاعبين، نظام نقاط، واستخدام قاعدة بيانات PostgreSQL لتخزين الأسئلة ونتائج المستخدمين، بالإضافة إلى دعمه القنوات الصوتية.
تمت الأستفادة من بنك البيانات المقدمة من قبل github.com/rn0x 
في عدة مشاريع بدعم من الدرر السنية
## 🌟 المميزات

- **نظام السؤال الفردي**: إرسال سؤال عشوائي حسب القسم ومستوى الصعوبة.
- **جلسات المسابقات (كويز)**: تشغيل مسابقة مكوّنة من عدة جولات مع نظام نقاط لتحديد الفائزين.
- **إعدادات تفاعلية**: استخدام أزرار ديسكورد لاختيار القسم (تفسير، حديث، فقه، وغيرها) ومستوى الصعوبة.
- **قاعدة بيانات قوية**: تخزين الأسئلة والإجابات ونقاط المستخدمين باستخدام PostgreSQL.
- **دعم Docker**: إمكانية تشغيل قاعدة البيانات والبوت بسهولة باستخدام Docker و Docker Compose.

## 🛠️ التقنيات المستخدمة

- **اللغة:** Go (Golang)
- **مكتبة ديسكورد:** `discordgo`
- **قاعدة البيانات:** PostgreSQL
- **إدارة التهجير (Migrations):** `goose`
- **الحاويات:** Docker و Docker Compose

## 🚀 كيفية التشغيل والتثبيت

### 1. المتطلبات الأساسية
تأكد من تثبيت الأدوات التالية على جهازك:
- [Docker](https://www.docker.com/) و Docker Compose
- [Go](https://golang.org/dl/) (في حال أردت تشغيل البوت محلياً بدون Docker)

### 2. إعداد ملف البيئة (`.env`)
أنشئ ملف باسم `.env` في المجلد الرئيسي للمشروع وأضف المتغيرات التالية، مع استبدال القيم بما يناسبك:

```env
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=hikmah
DB_HOST=localhost
DB_PORT=5432
DISCORD_TOKEN=your_bot_token_here
```

### 3. تشغيل قاعدة البيانات
لتشغيل قاعدة بيانات PostgreSQL باستخدام Docker بكل سهولة:

```bash
docker compose -f docker-compose.postgres.yml up -d
```

### 4. تنفيذ التهجير (Migrations)
لإنشاء جداول قاعدة البيانات الضرورية لعمل البوت:

```bash
goose -dir ./internal/database/migrations postgres "user=postgres password=your_password dbname=hikmah sslmode=disable" up
```

### 5. تشغيل البوت
أخيرًا، لتشغيل البوت محلياً باستخدام Go:

```bash
go run main.go
```
> **ملاحظة:** تأكد من أن مسار ملف `main.go` صحيح (في الإصدارات السابقة كان في `cmd/main.go` وفي هذا الإصدار يوجد في المسار الرئيسي `main.go`).

## 📂 هيكلة المشروع الأساسية

```text
├── bot/                       # معالجة الرسائل والتفاعلات في ديسكورد وإدارة الصوت
├── internal/database/         # ملفات إدارة الاتصال بقاعدة البيانات والتهجير
├── quiz/                      # منطق المسابقات وإدارة الجلسات
├── sql/                       # استعلامات SQL 
├── main.go                    # نقطة البداية لتشغيل البوت
└── docker-compose.*           # ملفات إعداد Docker
```
